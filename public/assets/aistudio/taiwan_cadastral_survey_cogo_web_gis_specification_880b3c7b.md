# 台灣數值法地籍測量暨複丈外業 Web GIS 圖台系統規格書

## 1. 系統概述與核心架構

本系統專為台灣地籍測量實務（內政部國土測繪中心 NLSC 數值法地籍圖重測與歷次複丈業務）設計，採用 **純前端單一網頁應用程式架構（Single-Page Web Application, RWD）**。無需架設後端伺服器，地籍機敏資料完全於使用者本機瀏覽器記憶體中解析與運算，兼顧資安規範與內外業行動化作業需求。

* **跨裝置支援：** 全面支援 Windows/macOS 桌機、iPad/Android 平板與智慧型手機。
* **坐標系統核心：** 內建 `Proj4js` 坐標轉換引擎，原生支援 **TWD97 二度分帶（121中央經線，EPSG:3826）** 與 **WGS84 經緯度（EPSG:4326）** 即時雙向無縫轉換。

## 2. 地圖圖台與底圖規格（Map & Basemaps）

### 2.1 底圖圖層（Basemaps）
圖台支援以下 4 種底圖即時切換：
1. **臺灣通用電子地圖（NLSC WMTS）：** 介接國土測繪中心 `EMAP` 圖磚服務，提供清晰道路、建物與地標輪廓。
2. **正射影像圖（NLSC WMTS）：** 介接國土測繪中心 `PHOTO2` 高解析度航照正射影像，供現場套疊比對現況。
3. **通用電子地圖混合版（Hybrid）：** 正射影像疊加通用電子地圖路網與地標文字註記（`EMAP2`）。
4. **OpenStreetMap（OSM）：** 開放街圖標準圖磚，作為備援與國際標準底圖。

### 2.2 圖台操作與導航互動（Map Interaction & Navigation）
* **極簡手勢與滑鼠操作：** 隱藏傳統繁瑣的 `+` / `-` 縮放按鈕，最大化地圖可視面積。
  * **行動裝置（手機/平板）：** 支援雙指捏合縮放（Pinch-to-zoom）、單指拖曳平移（Pan）。
  * **桌機版：** 支援滑鼠滾輪縮放（Scroll-wheel zoom）、左鍵拖曳平移。
* **GPS 裝置即時定位：**
  * 透過瀏覽器 Geolocation API 取得行動裝置 GPS 位置，即時轉換為 TWD97 $(N, E)$ 坐標顯示於狀態列，並在地圖上繪製帶有精度圓圈的藍色定位標記。
* **一鍵跳轉 Google Maps 外部導航：**
  * 點選地圖上任一「地號多邊形（取其重心或註記點）」、「界址點」、「圖根控制點」或「外業實測儲存點」時，資訊視窗（Popup）提供 **「🧭 Google Maps 導航至此點」** 按鈕。
  * 點擊後自動將該點之 TWD97 坐標反算為 WGS84 經緯度，並呼叫 `https://www.google.com/maps/dir/?api=1&destination={lat},{lng}` 喚起手機 Google Maps App 進行路徑導航。

## 3. 地籍交換檔資料夾結構與模擬測試資料

### 3.1 虛擬資料夾與地段切換機制
系統支援兩種資料載入模式，並提供 **「地段切換下拉選單」**：
1. **內建模擬測試資料夾（Demo Datasets）：** 預載兩組虛擬地段資料夾（例如 `臺東市_VA0001_示例段` 與 `臺東市_VA0002_重測示範段`），開啟網頁即可直接選擇地段進行測試。
2. **本機資料夾 / 多檔選取匯入（Local Folder / Batch Import）：** 支援 `<input type="file" webkitdirectory multiple>` 或拖曳資料夾，自動掃描資料夾內所有檔案，依據檔名前 6 碼（段代碼，如 `VA0001`）自動分組，讓使用者在下拉選單中自由切換不同地段。

### 3.2 八種標準地籍檔案解析規格與假數據範本

以下為系統內建之 `VA0001` 地段模擬測試數據（採用臺東市區 TWD97 二度分帶坐標），未來可直接替換為地政系統匯出之真實檔案：

#### ① `VA0001.COA`（界址點坐標檔）
* **格式：** Fortran 定長格式（點號 I6、N坐標 F12.3、保留/高程 I4、E坐標 F11.3、界標代碼 I5）。
```text
VA00011151120  50011511
  5458 2517100.00000000266500.00000001
  5465 2517120.00000000266500.00000001
  5464 2517120.00000000266525.00000002
  5463 2517100.00000000266525.00000002
  5462 2517100.00000000266550.00000003
  5468 2517120.00000000266550.00000001
  4808 2517080.00000000266500.00000002
  4810 2517100.00000000266500.00000001
  5441 2517100.00000000266525.00000002
  5440 2517080.00000000266525.00000000
```

#### ② `VA0001.BNP`（地號界址連線檔）
* **格式：** 母地號 I4、子地號 I4、卡片序號 I3、總點數 I4、依序排列之界址點號（每筆 I6）。
```text
VA0001    3
   4   1  1   4  5458  5465  5464  5463
   4   2  1   4  5463  5464  5468  5462
  44   1  1   4  4808  4810  5441  5440
```

#### ③ `VA0001.PAR`（宗地屬性與面積檔）
* **格式：** 新母子地號、登記面積、舊母子地號、坐標計算面積、地目/檢核碼、註記點 N/E 坐標。
```text
VA0001    3  0 0 07000
   4   1   1    500.00   4   1    500.00H 02517110.0266512.5  0
   4   2   1    500.00   4   2    500.00H 02517110.0266537.5  0
  44   1   1    500.00  44   1    500.00A 02517090.0266512.5  0
```

#### ④ `VA0001.CTL`（控制點及圖根點坐標檔）
* **格式：** 雙引號包覆點名 + N坐標 + E坐標。
```text
VAV0000000
"C689"  2517075.500266490.200  
"C690"  2517130.800266495.600  
"GO10"  2517125.400266560.800  
"GO11"  2517070.100266555.300  
```

#### ⑤ `VA0001.UPN`（都市計畫樁位坐標檔）
* **格式：** 靠左對齊樁號 + N坐標 + E坐標。
```text
VAV0000000
C666-1         2517065.000266500.000   
R179           2517065.000266550.000   
```

#### ⑥ `VA0001.RCO`（參考點坐標檔）
* **格式：** 同 `.COA` 結構，若無參考點則筆數為 `0`。
```text
VA0001    0
```

#### ⑦ `VA0001.MAP`（圖幅索引檔）
* **格式：** 記錄段代碼與分幅索引資訊。
```text
VA00016
```

#### ⑧ `VA0001.DIS`（界址邊長檢核檔）
* **格式：** 記錄實測邊長與坐標反算邊長較差，無異常時僅含段代碼檔頭。
```text
VA00016
```

## 4. 測繪計算工具箱（COGO）與現場點位管理

所有計算工具皆支援 **「🎯 點選地圖帶入坐標」** 功能，以及 **度分秒（`DDD.MMSS`）與十進位角度雙模式解析**。

### 4.1 專業測繪交會計算模組
1. **光線法（Radiation / Polar）：**
   * **輸入：** 測站點 $(N_0, E_0)$、後視點 $(N_{BS}, E_{BS})$（或直接輸入後視方位角）、觀測水平夾角 $\beta$、水平距離 $S$。
   * **輸出：** 目標點坐標 $(N_P, E_P)$、計算方位角 $\alpha_{0P}$。
2. **前方交會法（Intersection）：**
   * **方向角交會：** 輸入兩已知點 $A, B$ 與觀測方位角 $\alpha_{AP}, \alpha_{BP}$，求交點 $P$。
   * **距離交會（弧交會）：** 輸入兩已知點 $A, B$ 與觀測距離 $S_{AP}, S_{BP}$，同時計算並於地圖標示「解 1」與「解 2」，供外業人員直覺點擊選取正確側向之點位。
3. **後方交會法（Resection / 自由設站）：**
   * **三點後方交會（Tienstra / Collins 法）：** 輸入三個已知控制點 $A, B, C$ 與測站觀測之水平夾角 $\alpha, \beta$，反算未知測站 $P(N_P, E_P)$。
   * **危險圓防呆檢核：** 當測站與三已知點接近共圓（危險圓）時，系統自動計算幾何強度因子並跳出紅色警告提示。

### 4.2 外業實測點位儲存與管理系統（Field Point Manager）
* **一鍵儲存計算成果：** 任何透過光線法、前方交會、後方交會算出的點位，或直接輸入全測站/GNSS 實測坐標，皆可輸入「點號（如 `T01`）」、「點位備註（如 `實測圍牆角鋼釘`）」，點擊 **「💾 儲存至現場實測點庫」**。
* **本地持久化儲存（LocalStorage）：** 儲存的點位自動寫入瀏覽器本地儲存空間，重新整理網頁或關閉瀏覽器後資料不遺失，並以醒目的橘紅色星號圖層顯示於圖台上。
* **成果匯出：** 支援將外業實測儲存點一鍵匯出為 **CSV 坐標清冊** 或 **標準 `.COA` 增量交換檔**。

### 4.3 圖台量測與檢核工具（Measure & Check）
1. **簡易距離與方位角反算：**
   * 支援任意點選「現場實測點」、「界址點」、「圖根點」或「地籍線端點」，即時計算兩點間之 **水平距離（$\text{m}$，至公釐）**、**縱橫距差（$\Delta N, \Delta E$）** 與 **方位角（度分秒）**。
   * **點到地籍線垂距檢核：** 點選一條地籍界址線與一個實測點，立即顯示該實測點偏離地籍線的垂直距離（偏距，公分級檢核）。
2. **多邊形面積計算（坐標法）：**
   * 支援於地圖上依序點擊現有界址點、實測點或自由點選多邊形頂點，即時採用**高斯面積公式（Shoelace Formula）**計算閉合多邊形面積，同步顯示 **平方公尺（$\text{m}^2$）** 與 **坪數**，並可與 `.PAR` 檔之登記面積進行即時較差比對。

## 5. 使用者介面（UI/UX）響應式設計規劃

* **桌機版（Desktop $\ge 768\text{px}$）：**
  * 左側為可收合之「功能導航側邊欄」（分頁：資料夾與地段、圖層控制、COGO 計算、實測點庫、量測工具）。
  * 右側為全螢幕地圖視窗，底部狀態列即時顯示滑鼠游標 TWD97 坐標與比例尺。
* **行動版（Mobile / Tablet $< 768\text{px}$）：**
  * 全螢幕地圖優先，右上角配置浮動工具按鈕列（底圖切換、GPS 定位、圖層開關）。
  * 底部配置可三段式上下拖曳的「抽屜式操作面板（Bottom Sheet）」，外業操作單手即可完成輸入與地圖選點。
